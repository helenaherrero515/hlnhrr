# Project logo placeholders

Upload each project logo in this folder using these exact filenames. These logos appear inside the clicked project detail/info popout, while the main project cards keep the glassmorphism folder illustration.

- guidher-logo.png
- gising-logo.png
- tinig-logo.png
- lingap-logo.png
- purifai-logo.png
- convex-logo.png

Recommended format: transparent PNG or SVG-style PNG, square canvas, at least 800x800px.
If a logo file is missing, the detail popout shows the project's initials as a fallback.
